منشئ اختبارات المطابقة (صور وجمل)

حدد عدد الصور وارفع صوراً لكل حرف، ثم أضف جمل واختر الحرف الصحيح لكل جملة. الاختبار النهائي يعرض الصور بالأعلى والجمل بشكل عشوائي مع دوائر خيارات.
